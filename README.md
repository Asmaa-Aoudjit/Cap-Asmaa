# CSCC Parking Finder

A web application that helps students and employees at
Columbus State Community College find nearby and less crowded parking lots.

## Technologies Used
- HTML, CSS, JavaScript
- Python, FastAPI
- Mapbox API

## Features
- Interactive campus map
- Parking lot markers
- Favorites list
- Closest parking lot detection

## How to Run
1. Start the FastAPI backend
2. Open the frontend in a browser
3. Add your own Mapbox API key
